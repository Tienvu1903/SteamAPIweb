 PHAN 2: MO TA DU AN & BANG GIAI THICH DAY DU CAC TU VIET TAT
================================================================================

MO TA DU AN
-----------
Ung dung Cua hang Game thong minh: Du bao gia & Goi y game ca nhan hoa
- Nen tang ho tro:
  + Steam PC (Cua hang game tren may vi tinh ca nhan)
  + Nintendo Switch eShop (Cua hang game tren may choi game Nintendo Switch)
- Du lieu dau vao:
  + Doc 100% tu cac file CSV (Comma-Separated Values - Tep du lieu bang mo bang Excel)
  + Luu tru tai thu muc: E:\Steam_Machine_Learning\Game_data\data\cleaned_verified\
- Mo hinh Du bao gia trong 3 thang toi:
  + Cho 3 mo hinh Machine Learning (Hoc may) thi dau:
    1. Random Forest (Thuat toan Rung ngau nhien)
    2. Gradient Boosting (Thuat toan Tang cuong do doc)
    3. Ridge Regression (Thuat toan Hoi quy tuyen tinh Ridge)
- He thong Goi y game lai ghep (Hybrid Recommendation System):
  + Ket hop 3 cau truc thuat toan:
    1. SVD (Singular Value Decomposition - Phan ra gia tri suy bien / Loc cong tac)
    2. TF-IDF (Term Frequency-Inverse Document Frequency - Loc theo noi dung the loai)
    3. KNN (K-Nearest Neighbors - Thuat toan tim K lang gieng gan nhat)

BANG GIAI THICH TOAN BO KY HIEU & TU VIET TAT
---------------------------------------------
1. Thuat ngu He thong & May tinh:
   - AI     : Artificial Intelligence (Tri tue nhan tao)
   - ML     : Machine Learning (Hoc may - May tinh tu hoc quy luat tu du lieu)
   - CSV    : Comma-Separated Values (Tep bang du lieu phan cach bang dau phay, mo bang Excel)
   - CMD    : Command Prompt (Cua so dong lenh mau den cua he dieu hanh Windows)
   - PC     : Personal Computer (May vi tinh ca nhan)
   - UI     : User Interface (Giao dien nguoi dung tren trang Web)
   - URL    : Uniform Resource Locator (Duong dan / Dia chi trang Web)

2. Thuat ngu Game & Cua hang:
   - AppID  : Application Identification (Ma so dinh danh duy nhat cua tung tua game)
   - User   : Nguoi dung / Nguoi choi game (Game thu)
   - CCU    : Concurrent Users (So luong nguoi dang choi game truc tuyen cung mot luc)
   - 1h     : 1 gio qua (So nguoi choi tinh trong 1 tieng gan nhat)
   - 24h    : 24 gio qua (Dinh so nguoi choi cao nhat trong vong 1 ngay qua)
   - 3T     : 3 Thang toi (Khoang thoi gian AI du doan gia game trong tuong lai)
   - F2P    : Free-to-Play (Game mien phi 100%, gia ban = $0.00)
   - Sale   : Dot giam gia / Chuong trinh khuyen mai
   - RPG    : Role-Playing Game (The loai game nhap vai)
   - FPS    : First-Person Shooter (The loai game ban sung goc nhin thu nhat)

3. Thuat ngu Thuat toan & Chi so danh gia Mo hinh:
   - RF     : Random Forest (Mo hinh Rung ngau nhien)
   - SVD    : Singular Value Decomposition (Ma tran phan rã tương tác giữa Người dùng và Game)
   - TF-IDF : Term Frequency-Inverse Document Frequency (Danh gia muc do tuong dong ve the loai)
   - KNN    : K-Nearest Neighbors (Tim kiem cac tua game co chi so gan giong nhau nhat)
   - MAE    : Mean Absolute Error (Sai so tuyet doi trung binh - Chi so nay cang nho cang tot)
   - RMSE   : Root Mean Square Error (Can bac hai sai so binh phuong trung binh - Cang nho cang tot)
   - R2     : R-Squared / He so xac dinh (Do chinh xac cua mo hinh, cang gan 1.0 la cang chinh xac)

B. 5 TRANG CHÍNH TRÊN MÀN HÌNH (5 TABS):
   1. 🎮 Cua Hang Goi Y:
      - Hien thi truc tiep "Bang Game Hien Tai Dang So Huu" cua nguoi dung dang chon.
      - Hien thi danh sach game AI de xuat mua (da loai tru 100% cac game trong bang so huu).
      - Tren moi the game hien thi ro 3 cot gia:
        + Cot 1 (Gia Hien Tai / Gia Sale): Gia dang ban kem Gia goc va % giam gia.
        + Cot 2 (Du Bao 3T Toi): Gia du doan trong 3 thang toi ("↑ Het sale" hoac "↓ Cho sale").
        + Cot 3 (Day Lich Su): Muc gia thap nhat lich su cua tua game do.
      - Co 2 nut bam: Nut mo thang trang san pham tren Steam Store / Nintendo eShop va nut xem 
        chi tiet diem so AI (SVD, TF-IDF, KNN) kem luong nguoi choi CCU.

   2. 📦 Kho Game Dang So Huu:
      - Xem bang chi tiet toan bo kho game cua nguoi dung va bieu do cot so sanh so gio choi.

   3. 🔥 Xep Hang CCU:
      - Bieu do va danh sach Top 10 tua game co so nguoi dang choi cung luc (CCU 1h va Dinh 24h) cao nhat.

   4. 🏷️ San Sale & Gia 3T:
      - O tim kiem ten game bat ky va bo loc nhanh cac game "🟢 Mua Ngay" hoac "🔥 Dang Sale".

   5. 📊 Bang CSV & Mo Hinh:
      - Xem bang xep hang 3 mo hinh Du Bao Gia, bao cao 3 cau truc Hoc May Goi Y va xem truc tiep 
        noi dung cac file CSV ngay tren Web.
