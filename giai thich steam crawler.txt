1. THUẬT TOÁN ƯỚC TÍNH SỐ NGƯỜI SỞ HỮU GAME — Hàm `parse_owners(owners_str)`
--------------------------------------------------------------------------------
a) Ý nghĩa:
   - Vì chính sách bảo mật của Valve, SteamSpy không trả về con số chính xác có
     bao nhiêu người đã mua game, mà trả về một chuỗi khoảng (Range), ví dụ:
     `"1,000,000 .. 2,000,000"`.
   - Máy tính không thể nhân chia chuỗi chữ này được, nên ta phải lấy điểm giữa
     (trung bình cộng) của cận dưới ($Low$) và cận trên ($High$).

b) Công thức toán học:
   $$Owners_{est} = \lfloor \frac{Low + High}{2} \rfloor$$
   Trong đó:
   - $Low$: Số người sở hữu tối thiểu (cận dưới).
   - $High$: Số người sở hữu tối đa (cận trên).
   - Dấu $\lfloor \dots \rfloor$ (trong Python là phép chia lấy nguyên `// 2`): Đảm bảo
     số người luôn là số nguyên.

c) Dẫn chứng Code trong `1_steam_crawler.py`:
```python
def parse_owners(owners_str: str) -> int:
    """Chuyển chuỗi khoảng sở hữu '1,000,000 .. 2,000,000' thành con số trung bình (1500000)."""
    try:
        clean_str = str(owners_str).replace(",", "")  # Bỏ hết dấu phẩy -> "1000000 .. 2000000"
        parts = clean_str.split("..")                 # Cắt đôi tại dấu ".."
        if len(parts) == 2:
            low = int(parts[0].strip())               # Cận dưới = 1000000
            high = int(parts[1].strip())              # Cận trên = 2000000
            return (low + high) // 2                  # Cộng lại chia nguyên cho 2
        return 0
    except (ValueError, TypeError, IndexError):
        return 0
```

d) Ví dụ tính nhẩm cụ thể:
   - Input từ API: `owners_str = "5,000,000 .. 10,000,000"`
   - Bước 1: Xóa dấu phẩy $\rightarrow$ `"5000000 .. 10000000"`
   - Bước 2: Tách tại `".."` $\rightarrow Low = 5000000$, $High = 10000000$
   - Bước 3: $Owners_{est} = (5000000 + 10000000) // 2 = 7500000$ người sở hữu.

2. THUẬT TOÁN TỰ SUY LUẬN THỂ LOẠI GAME — Hàm `generate_inferred_tags(...)`
--------------------------------------------------------------------------------
a) Ý nghĩa:
   - Khi quét hàng ngàn game cùng lúc, API tổng của SteamSpy thường bỏ trống cột
     thể loại (`tags`) để tiết kiệm băng thông. Nếu gọi API chi tiết cho cả 1.000
     game thì sẽ mất hơn 15 phút.
   - Giải pháp thông minh: Chỉ gọi API chi tiết (`fetch_app_tags`) cho Top 20 game
     đầu tiên, còn các game phía sau sẽ dùng hàm `generate_inferred_tags` để tự
     suy luận nhãn thể loại dựa trên 4 thông số thực tế: Giá tiền (`price`),
     Lượng người chơi (`ccu`), Thời gian chơi (`avg_playtime`) và Điểm đánh giá (`pos_ratio`).

b) Quy tắc phân nhánh suy luận trong Code:
   - Nhóm 1 (Theo Giá tiền `price`):
     + $Price == 0 \rightarrow$ Gắn nhãn `"Free to Play"`
     + $Price \ge \$40 \rightarrow$ Gắn nhãn `"AAA"` (Game bom tấn kinh phí lớn)
     + $0 < Price < \$40 \rightarrow$ Gắn nhãn `"Indie"`
   - Nhóm 2 (Theo Lượng người chơi `ccu`):
     + $CCU \ge 10,000 \rightarrow$ `"Multiplayer", "Competitive", "Co-op"`
     + $1,000 \le CCU < 10,000 \rightarrow$ `"Action", "Multiplayer"`
     + $CCU < 1,000 \rightarrow$ `"Singleplayer", "Adventure"`
   - Nhóm 3 (Theo Thời gian chơi trung bình tính bằng phút `avg_playtime`):
     + $Playtime \ge 1200$ phút ($\ge 20$ giờ) $\rightarrow$ `"RPG", "Strategy", "Simulation"`
     + $300 \le Playtime < 1200$ phút ($5 \dots 20$ giờ) $\rightarrow$ `"Action", "Open World"`
     + $Playtime < 300$ phút ($< 5$ giờ) $\rightarrow$ `"Casual", "Arcade"`
   - Nhóm 4 (Theo Điểm đánh giá `pos_ratio`):
     + $Pos\_Ratio \ge 90\% \rightarrow$ Gắn thêm nhãn `"Masterpiece"` (Tuyệt phẩm).

c) Dẫn chứng Code trong `1_steam_crawler.py`:
```python
def generate_inferred_tags(price: float, ccu: int, avg_playtime: int, pos_ratio: float) -> str:
    tags = []
    if price == 0:
        tags.append("Free to Play")
    elif price >= 40:
        tags.append("AAA")
    else:
        tags.append("Indie")

    if ccu >= 10000:
        tags.extend(["Multiplayer", "Competitive", "Co-op"])
    elif ccu >= 1000:
        tags.extend(["Action", "Multiplayer"])
    else:
        tags.extend(["Singleplayer", "Adventure"])

    if avg_playtime >= 1200:
        tags.extend(["RPG", "Strategy", "Simulation"])
    elif avg_playtime >= 300:
        tags.extend(["Action", "Open World"])
    else:
        tags.extend(["Casual", "Arcade"])

    if pos_ratio >= 90:
        tags.append("Masterpiece")

    unique_tags = list(dict.fromkeys(tags))  # Loại bỏ từ khóa bị trùng lặp
    return ", ".join(unique_tags[:6])        # Lấy tối đa 6 nhãn đầu tiên
```

3. THUẬT TOÁN ĐÁNH GIÁ TÍN HIỆU MUA — Hàm `evaluate_game_signal(...)`
--------------------------------------------------------------------------------
a) Công thức phân loại 4 mức tín hiệu (`STRONG_BUY`, `BUY`, `AVOID`, `HOLD`):
   - **STRONG_BUY (Mua ngay lập tức):**
     Khi $Review\_Pct \ge 85\%$ **VÀ** thỏa mãn ít nhất 1 trong 3 điều kiện:
     ($Discount \ge 30\%$ HOẶC $Price \le \$15.0$ HOẶC $CCU \ge 5000$).
   - **BUY (Đáng mua):**
     Khi $Review\_Pct \ge 75\%$ **VÀ** $Price \le \$39.99$.
   - **AVOID (Cảnh báo tránh mua):**
     Khi $Review\_Pct < 55\%$ (game bị chê nhiều) **VÀ** $Price > \$10.0$.
   - **HOLD (Tạm giữ / Chờ đợt giảm giá):**
     Tất cả các trường hợp còn lại (ví dụ: game hay nhưng đang bán nguyên giá $\$59.99$).

b) Dẫn chứng Code trong `1_steam_crawler.py`:
```python
def evaluate_game_signal(price: float, review_pct: float, discount: int, ccu: int) -> str:
    if review_pct >= 85 and (discount >= 30 or price <= 15.0 or ccu >= 5000):
        return "STRONG_BUY"
    if review_pct >= 75 and price <= 39.99:
        return "BUY"
    if review_pct < 55 and price > 10.0:
        return "AVOID"
    return "HOLD"
```

4. THUẬT TOÁN TÍCH LŨY LỊCH SỬ & TÍNH BIẾN ĐỘNG — Hàm `save_accumulated_data(...)`
--------------------------------------------------------------------------------
a) Nguyên lý hoạt động:
   - Bước 1: Ghép bảng lịch sử cũ (`old_df`) và bảng mới cào (`new_df`) bằng `pd.concat`.
   - Bước 2: Khử trùng lặp theo bộ 3 khóa `["date", "hour", "app_id"]`:
     + Nếu trong **cùng 1 giờ của cùng 1 ngày** bạn bấm chạy 2 lần $\rightarrow$ Chỉ giữ bản
       mới nhất (`keep="last"`).
     + Nếu **khác giờ hoặc khác ngày** $\rightarrow$ Giữ nguyên cả 2 dòng để tạo chuỗi thời gian.
   - Bước 3: Sắp xếp theo `["app_id", "timestamp"]` và dùng hàm `.groupby("app_id").diff()`
     để lấy dòng sau trừ dòng trước của đúng tựa game đó:
     $$CCU\_Change_t = CCU_t - CCU_{t-1}$$
     $$Price\_Change_t = Price_t - Price_{t-1}$$
     $$Review\_Growth_t = Total\_Reviews_t - Total\_Reviews_{t-1}$$

b) Dẫn chứng Code trong `1_steam_crawler.py`:
```python
combined_df = pd.concat([old_df, new_df], ignore_index=True)
combined_df = combined_df.drop_duplicates(subset=["date", "hour", "app_id"], keep="last")
combined_df = combined_df.sort_values(["app_id", "timestamp"]).reset_index(drop=True)

# Tính toán biến động thực tế so với lần cào liền trước của từng game
combined_df["ccu_change"] = combined_df.groupby("app_id")["ccu"].diff().fillna(0).astype(int)
combined_df["price_change"] = combined_df.groupby("app_id")["price"].diff().fillna(0.0).round(2)
combined_df["review_growth"] = combined_df.groupby("app_id")["total_reviews"].diff().fillna(0).astype(int)
combined_df["history_Points"] = combined_df.groupby("app_id").cumcount() + 1
```


III. CÂU HỎI VẤN ĐÁP THƯỜNG GẶP VỀ FILE 01 (ĐỂ TRẢ LỜI GIẢNG VIÊN)
================================================================================
- **Câu hỏi 1:** *"Tại sao trong code phải chia giá `price` của SteamSpy cho `100.0`?"*
  $\rightarrow$ **Trả lời:** Vì API của SteamSpy lưu giá tiền theo đơn vị **Xu (Cents)** của Mỹ
  để tránh sai số dấu phẩy động (ví dụ: $\$19.99$ được trả về là `1999`). Do đó phải chia
  cho `100.0` mới ra đơn vị Đô-la Mỹ ($\$19.99$).

- **Câu hỏi 2:** *"Làm sao để cào nhiều lần trong ngày mà không bị trùng dữ liệu rác nhưng vẫn giữ được lịch sử?"*
  $\rightarrow$ **Trả lời:** Em dùng lệnh `drop_duplicates(subset=["date", "hour", "app_id"], keep="last")`.
  Lệnh này khóa theo Ngày + Giờ + Mã Game: nếu cào lặp lại trong cùng 1 tiếng thì nó ghi đè
  bản mới nhất của tiếng đó, còn sang tiếng tiếp theo hoặc ngày hôm sau thì nó tự động lưu
  thành dòng lịch sử mới.
